## 3. 传动链

```
1404 KV3800 外转子 → 10:1 行星 → 10:36 齿轮 → 曲柄 560 rpm ≈ 9.3 Hz
```

早期版本用 1104 KV7500 + 3.6:1，算下来 257 Hz，和扑翼 8 Hz 差两个数量级——这是个典型
"数字好看但物理不成立"的错误，改造时按 9.3 Hz 反推了减速比。

## 4. 曲柄摇杆（四杆机构）

曲柄旋转通过球头扣、碳连杆驱动肩摇臂，反解摆角：

```js
var ROD_DX = 1, ROD_PLANAR = 30;                       // 连杆平面投影长度 30 mm
var HORN_R = Math.sqrt(1.2*1.2 + 13.5*13.5);           // 摇臂半径 ≈ 13.55 mm
var HORN_THETA0 = Math.atan2(-1.2, 13.5);              // 初始相位
```

- 连杆长度在两圆求交时保持恒定为 **30.02 mm**（可验证：任意曲柄角下误差 < 0.01 mm）
- 摆角输出 **±30.6°**，与肩关节 ±32° 的机械限位留 1.4° 余量
- 两端都用 M2 球头扣：可换向、可微调长度，避免装配误差顶死

## 5. 气动校核（准稳态叶素）

| 项目 | 原方案 | 改造后 |
|---|---|---|
| 翼展 | 725 mm | 840 mm |
| 翼面积 | 785 cm² | 1028 cm² |
| 翼载 | 16.6 g/dm² | 13.6 g/dm² |
| 8 Hz 所需升力占可用 | 53–89% | 余量 +18% ~ +97% |

结论：原方案在最不利相位升力不够，飞不起来；改造后有余量。
翼根弯矩 0.145 N·m，Ø3×Ø2 碳管应力 68 MPa，安全系数 8.8。

## 6. 飞控（ESP32）

- 三轴增稳：MPU6050/ICM 系列 IMU，200 Hz 姿态解算
- 混控输出：2 路腕部舵机（差动扭翼）+ 升降舵 + 方向舵
- 控制律：横滚差分扭翼为主、方向舵为辅——低速扑翼机方向舵效率低，必须先倾后转
- 升降靠"油门 + 拉杆"配合，单拉杆会掉速

## 8. 空气动力模拟

流场是解析式的准稳态模型，不是 CFD：

| 分量 | 作用 |
|---|---|
| 自由来流 | 沿 −z 方向，2–6 m/s |
| 机体排开 | 细长体势流 `a²/r²`，把流线推到机身两侧 |
| 前缘上洗 | 机翼前方气流提前上抬绕开 |
| 展向下洗 | 椭圆分布 `(1−(x/b)²)^0.55`，翼尖归零 |
| 上下环流 | `tanh(y/58)`，上表面抬起、下表面下压 |
| 翼尖涡 | Lamb-Oseen 涡核（`CORE = 48 mm`），左右反向 |
| 三轴耦合 | elev 改下洗强度、roll 让两侧不对称、yaw 给侧洗 |

颜色编码与面板图例一致：**蓝 = 正常气流 / 橙 = 下洗 / 绿 = 上洗**。

流线积分用 RK1，步长沿流向 7 mm；每条流线画 3 条偏移 ±1.5 mm 的平行线束，因为
WebGL 的 `LineBasicMaterial.linewidth` 恒为 1 px，靠叠加才能有厚度。
